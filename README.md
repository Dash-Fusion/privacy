## Editing

Each policy is a single Markdown file with YAML front-matter so Jekyll on GitHub Pages renders it as HTML. To update a policy:

1. Edit the relevant `.md` file
2. Bump the `Last updated` date in the body
3. Commit to `main` — Pages republishes automatically (usually within ~1 minute)
